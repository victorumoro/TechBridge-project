 TechBridge Landing Page

A responsive landing page project for **TechBridge**, designed to showcase programs, internships, and community initiatives.  
The goal of this project is to connect learning with real-world experience through a clean, modern, and mobile-friendly interface.

Features
- Responsive Navigation Bar** with hamburger toggle for mobile devices
- Hero Section** with tagline, description, image, and call-to-action buttons
- Offerings Section** highlighting:
  - Web Development
  - Data Analytics & AI
  - Practical Internship Programs
- Footer Section** with contact information and social media links
- Font Awesome Integration** for icons
- Modern CSS Styling** with flexbox and media queries

Tech Stack
- HTML5 for structure
- CSS3 (Flexbox, Media Queries) for styling and responsiveness
- Font Awesome** for icons
- JavaScript for interactive navigation toggle
